## Purpose

Use this file when writing, repairing, or reviewing a classical geometry multiple-choice problem from the HH co dien bank.

## Core observation

These MC problems usually do not need heavy calculation. They are solved by spotting one canonical structure and replacing the target with a familiar object.

Typical structures:

- projection of a line onto a plane
- parallel or equal vector replacement in a parallelogram
- centroid identity in a tetrahedron
- midpoint or section-ratio conversion
- regular tetrahedron, regular pyramid, cube, or prism symmetry
- edge, face diagonal, and space diagonal comparison
- isosceles-triangle angle split

## Solve-the-stem algorithm

1. Identify the solid and privileged structure.
2. Mark the exact target: angle, dot product, vector identity, point location, or vector length.
3. Replace the target by an equivalent standard object.
4. Add one auxiliary point only if it unlocks a theorem.
5. Use the shortest valid property chain.
6. Check that distractors remain plausible and wrong.

## Canonical moves

- Line-plane angle: project the line onto the plane and name the resulting angle.
- Vector angle: replace one vector by a parallel or equal vector, then use a familiar triangle angle.
- Vector identity: express vectors from one origin and use base-vector cancellation.
- Regular tetrahedron dot product: use a midpoint and perpendicular plane argument to make several dot products vanish.
- Centroid relation: convert to `AB + AC + AD = 3AG`, then reduce to a midpoint or ray statement.
- Edge ratio: convert the ratio into a full-edge relation before expanding the asked vector.
- Cube lengths: classify each vector as edge, face diagonal, or space diagonal.

## Distractor design

Good distractors come from nearby mistakes:

- wrong projected angle
- forgotten supplementary angle
- apex angle instead of base angle
- face diagonal confused with edge
- dropped vector sign
- midpoint confused with another section ratio
